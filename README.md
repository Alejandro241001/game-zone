Breve descripción del proyecto:

Game-Zone será una página web diseñada para los usuarios que quieran una lista extensa de videojuegos, crear tus propias listas con videojuegos que hayas jugado, consultar detalles como notas de Metacritic, leer y escribir reseñas. La página ofrecerá funcionalidades como listas personalizadas, nota de cualquier videojuego que esté en la base de datos, dejar una reseña propia y puntuar el propio videojuego. El proyecto contará con tres Roles(usuario no registrado, usuario registrado y administrador).

El objetivo es crear un entorno funcional a la cual que sea vistoso para los usuarios y sencilla de manejar.
